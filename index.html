Why Canva changes text, and how “For Canva” avoids it

When Canva imports a PDF, it re-types the text with its own fonts, and Hindi conjuncts and matras get lost. In “For Canva” mode each slide is a single high-resolution picture, so there is no text for Canva to re-type: what you see is exactly what comes back.

Original PDF mode

Each page is moved into a new file with its images, fonts and graphics byte-for-byte identical. If several slides share an image or font, each part gets its own copy, so every part opens on its own.
